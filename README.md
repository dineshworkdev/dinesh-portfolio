# Dinesh M — Personal AV Industry Portfolio

A personal portfolio and resume website for **Dinesh M**, an aspiring Audio-Visual (AV) industry professional and B.Sc. Computer Technology graduate. Built with semantic HTML5, modular vanilla CSS, and lightweight vanilla JavaScript.

## 🚀 Key Highlights

- **AV Industry Positioning**: Showcases foundational knowledge across Audio, Video, Lighting, AV Control Systems, Networking, Cabling, Embedded Systems, and IoT.
- **HARMAN Professional Training**: Highlights all eight completed HARMAN Professional Training courses.
- **Academic & Internship Profile**: Presents education (B.Sc. Computer Technology, SRCAS Coimbatore), internships, and leadership achievements.
- **Accessible & Responsive**: Semantic HTML5 landmark structure with keyboard focus styling, mobile navigation drawer, and skip links.

---

## 📁 Project Folder Structure

```
├── index.html                 # Main single-page document (semantic HTML5)
├── README.md                  # Project documentation
├── assets/
│   ├── css/
│   │   ├── variables.css      # Design tokens (palette, typography, spacing, shadows)
│   │   ├── base.css           # CSS resets, typography, container utilities, accessibility
│   │   ├── components.css     # Buttons, badges, cards, form controls
│   │   └── sections.css       # Section-specific layout and responsive styles
│   ├── js/
│   │   ├── main.js            # Main application entry point & scroll reveal
│   │   ├── navigation.js      # Mobile menu and scroll-spy handlers
│   │   └── form.js            # Contact form validation and submission
│   └── images/
│       └── icons/             # Brand monogram logo and icons
```
